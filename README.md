# Grass Pass

Grass Pass is a Chromium Manifest V3 extension that blocks a user-defined list of doomscroll sites until the user completes a short real-world challenge. The design keeps verification local, uses a device-first vision pipeline, and fails closed when model or storage state is uncertain.

## Features

- MV3 service worker with blocklist enforcement
- Blocked-page interstitial and challenge flow
- Webcam and upload capture with EXIF freshness checks
- Local vision verification through Transformers.js or a local Ollama instance
- Unlock timer with automatic re-lock and badge countdown
- Settings, stats, and friction guard for delayed weakening changes

## Quick start

1. Install dependencies:
   pnpm install
2. Run the extension in development mode:
   pnpm dev
3. Load the unpacked extension from the `.wxt` folder generated by WXT.
4. Open Chrome and visit a blocked domain to trigger the interstitial flow.

## Local demo

For a deterministic local demo without a real model dependency:

pnpm demo:local

This runs the extension with the fake vision backend so the challenge flow can be exercised without model downloads.

## Production build

Build the extension bundle:

pnpm build

For a local/offline packaging pass:

pnpm build:offline

## Packaging

To create a zip artifact for manual QA or distribution:

pnpm zip

The zip is written by WXT into the build output folder.

## Privacy and security

- No account, cloud, or remote inference is required for normal use.
- The extension does not send image data to a remote service by default.
- Optional Ollama requests stay on localhost only.
- The extension fails closed: if verification fails or state cannot be confirmed, blocked sites remain blocked.

## Config flags

The project supports the environment variables documented in the implementation spec. A starter file is included at [.env.example](./.env.example).

## Demo script

1. Open Chrome with the extension loaded.
2. Visit a blocked domain such as `reddit.com`.
3. Complete a one-slot challenge or a short leaf challenge.
4. Confirm the original page opens again after the unlock period.
5. Wait for the automatic re-lock and confirm navigation returns to the blocked page.

## Notes

This repository is intentionally conservative and test-driven. The scaffold keeps the extension deterministic, typed, and ready for local vision verification, while staying within the platform constraints for Manifest V3 and Chromium.
